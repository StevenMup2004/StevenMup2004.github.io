AI Engineer & Researcher

Vu Hai Dang

I work on the security of large language models applied to software: secure code generation, keeping code models aligned with APIs as they change, and defending retrieval-augmented systems against poisoning.

My interest is in results that survive contact with real systems — robustness, safe deployment, and knowledge that stays correct as the software around it moves.
