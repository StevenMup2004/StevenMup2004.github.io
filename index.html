About

Research that survives contact with real systems

My research lies at the intersection of software engineering, artificial intelligence and cybersecurity. I work on LLM4Code — large language models applied to code — focusing on secure code generation, keeping code models aligned with APIs as they evolve, and defending retrieval-augmented systems against poisoning.

Natural language processing underpins all of it: these systems read specifications, issues and documentation long before they emit a line of code. What ties the threads together is an interest in results that survive contact with real systems — robustness, safe deployment, and knowledge that stays correct as the software around it moves.

What I work on

Four threads, one recurring question: when can you actually trust a model with code?

LLM security

How large language models fail under adversarial pressure, and what makes their behavior dependable enough to deploy.

Secure code generation

Getting models to produce code that is correct and safe, not merely plausible.

AI for software engineering

Where models genuinely help with maintenance, migration, and reasoning about code that already exists.

Retrieval and agents

Grounding, retrieval quality, and guardrails for systems that act rather than only answer.
